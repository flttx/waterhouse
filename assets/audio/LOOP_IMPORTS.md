# Original sound palette

Generated by `tools/generate_audio.py`, deterministic standard-library synthesis, 22050 Hz PCM16.
facility/submerged/pump/heartbeat are looped via native Godot WAV import settings. Other cues are one-shot sounds.
Audio mix uses native AudioStreamPlayer3D distance attenuation, room reverb, and underwater low-pass filtering.
These are playable placeholder sound designs; a commercial master should replace the mechanical/noise cues with recorded foley.
